# Local Ad Booster

I want to build a clickable prototype (no backend, no payments, no external APIs — mock data only) of a mobile-first web app.

The app is a managed advertising service for very small local businesses in the Netherlands. The business owner answers a few questions, adds credit to a wallet, and we run their Facebook, Instagram and Google ads for them. They see a simple dashboard of results.

Users are non-technical business owners (plumbers, hair salons, restaurants, dentists) who have never run ads and are nervous about wasting money.

Before we build anything: what screens would you recommend, what's the simplest navigation structure, and what should I be careful about when prototyping this without a backend?
